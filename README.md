# Dead-Shop-3D


Dead Shop: A zombie game where you play as Patient Zero, lead your horde, and kill as many survivors as you can to grow your numbers before more reinforcements arrive. These games are in their very early stages, and I am working on them alone. I cannot wait to show you what I have in store.


For the first project, I added all the scripts, pause menu, camera follow player movement, etc. For this project, I have the same scripts, but this project is 3D, not 2D like the last project. My goal for this project is to have a playable demo. As seen in my scene, there is groundwork, and I just have to implement scripts and some sensors to get the NPC to behave I want them to.
